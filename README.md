# TodoList

A todo list app for macOS built by Codex.  
100% vibe coded. Use at your own risk.  
User data is saved in `~/Library/Application Support/TodoList/todos.json`.  


## Build And Run
This app has been built and only tested for macOS 27. Xcode is required to built from source.
```
bash ./script/build_and_run.sh
```
This create the `dist/TodoList.app` that can be moved to your `Applications/`.
