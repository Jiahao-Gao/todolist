# TodoList

A minimal todo list app for macOS.  
(This project was generated by Codex. Use at your own risk.)  
Data is saved in `~/Library/Application Support/TodoList/todos.json`


## Build And Run
```
bash ./script/build_and_run.sh
```
If Xcode has not been launched before, accept the Xcode license in Terminal then run the build script again:
```bash
sudo xcodebuild -license
```

## Test
```bash
swift test
```
